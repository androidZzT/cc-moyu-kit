# market-pane

在 Claude Code 侧边面板里看行情，vibecoding 的时候瞄一眼大盘，不用切出终端。

- **指数**：A股（上证指数、深证成指、创业板指）、港股（恒生指数、恒生科技指数）、美股（道琼斯、纳斯达克、标普500）
- **自选股**：最多 20 只，跨会话保留
- **走势线**：每个标的第二行画当日走势，旁边一根按涨跌幅比例的条形
- **关注板块**：半导体（芯片概念）、人工智能、机器人、券商、创新药，每个板块显示当日涨跌幅和板块内涨幅前三、跌幅前三的公司（剔除 ST）；想换板块改 `hooks/boards.ts`
- **跳动高亮**：现价比上次刷新有变化时，反色显示一个刷新周期
- **低打扰**：不抢输入焦点，没有弹窗和声音；拉取失败时继续显示旧数据，并标上「过期」

- 红涨绿跌，并用 ▲/▼ 标方向，不显示颜色的终端也能看出涨跌
- 现价带千分位，涨跌额带 +/- 号，三列数字右对齐
- 走势线按当天自己的最高、最低价缩放；最新价高于昨收为红，低于为绿
- 条形每格代表 1%，精度 1/8 格，涨跌 4% 及以上画满
- 板块：板块涨跌幅与指数同色规则；成分股左列涨幅前三、右列跌幅前三；取不到时显示「板块数据暂不可用」

## 加载

在 Claude Code 终端会话里安装：

```
/plugin install market-pane --marketplace androidZzT/cc-moyu-kit
```

或者从源码加载：

```bash
claude --plugin-dir /path/to/cc-moyu-kit/mods/market-pane
```

终端宽度 ≥144 列时，会话启动后面板自动出现在右侧。窄于 144 列时 Claude Code 不让面板自动占位，需要用 `/market` 手动打开。

## 命令

| 命令 | 作用 |
| --- | --- |
| `/market` | 开关面板 |
| `/market add <代码> [名称]` | 添加自选；已经添加过的代码会改成新名称 |
| `/market remove <代码>` | 删除自选 |
| `/market list` | 列出自选 |
| `/market play` | 在行情和 K 线猜涨跌之间切换（游戏内 ↑/↓ 猜涨跌，Enter 下一局，q 退出） |

代码格式：

| 市场 | 格式 | 示例 |
| --- | --- | --- |
| A股 | `sh` / `sz` / `bj` + 6 位数字 | `sh600519`、`sz000001` |
| 港股 | `hk` + 5 位数字 | `hk00700` |
| 美股 | `us` + 代码 | `usAAPL`、`usBRK.B` |

接口返回的中文名是 GBK 编码，mod 读不了，所以自选股显示的是你给的名称；没给名称就显示代码。

## 刷新

| 数据 | 盘中 | 休市 |
| --- | --- | --- |
| 报价与关注板块（任一市场盘中即算盘中） | 每 10 秒 | 每 5 分钟 |
| A股/港股分时走势 | 每 60 秒 | 每 30 分钟 |
| 板块成分股涨跌榜（按 A股时段） | 每 60 秒 | 每 30 分钟 |

- 面板关闭时什么都不请求；打开面板或新增自选时，没有走势的标的立即补拉
- 分时接口一次只能查一个代码，每次最多并发 5 个
- 美股接口没有分时数据，走势线用面板打开期间每次报价刷新的价格采样，所以刚打开时美股走势是空的，面板关着的时间段也没有数据；每个美股交易日重新开始
- 交易时段按北京时间判断，美股自动处理夏令时；不处理节假日，节假日按交易日算，最多多刷几次
- 任何一类数据取不到时都保留上一次的数据，不弹窗，也不影响其他数据

## 数据源

都是腾讯行情的公开接口，不需要 key：

| 用途 | 接口 |
| --- | --- |
| 报价与板块 | `https://qt.gtimg.cn/q=<代码,...>`（板块代码如 `pt02003891`） |
| 分时走势 | `https://ifzq.gtimg.cn/appstock/app/minute/query?code=<代码>` |
| 板块成分股涨跌榜 | `http://proxy.finance.qq.com/cgi/cgi-bin/rank/hs/getBoardRankList?board_code=<板块代码>&...`（https 证书宿主不信任，只能走 http） |
| 日 K（游戏） | `https://ifzq.gtimg.cn/appstock/app/fqkline/get?param=<代码>,day,,,320,qfq` |

这些都是非官方接口，没有可用性保证，接口变更或限流时对应数据会停在上一次（报价会标「过期」）。行情仅供参考，不构成投资建议。

## 开发

```bash
claude plugin validate .
claude plugin test .
npx -p typescript tsc -p .   # 先用 --plugin-dir 加载一次，生成 .claude-plugin/types
```

| 文件 | 内容 |
| --- | --- |
| `hooks/register.tsx` | 所有用到 `$` 的逻辑：事件接线、刷新、命令、state |
| `hooks/symbols.ts` | 代码校验、内置指数 |
| `hooks/parse.ts` | 报价 URL、解析响应、跳动比较 |
| `hooks/trend.ts` | 分时解析、美股采样、重采样、走势线字符 |
| `hooks/bars.ts` | 涨跌幅条形 |
| `hooks/boards.ts` | 关注板块配置：代码与显示名 |
| `hooks/movers.ts` | 成分股涨跌榜 URL、解析、剔除 ST |
| `hooks/hours.ts` | 交易时段、刷新间隔 |
| `hooks/watchlist.ts` | 自选增删、子命令解析 |
| `hooks/view.tsx` | 面板绘制：指数与自选的两行布局 |
| `hooks/boards-view.tsx` | 板块绘制：标题 + 涨跌前三两列 |
| `hooks/kline.ts` | 日 K URL 与解析 |
| `hooks/game.ts` | 题库、出题、判定、计分 |
| `hooks/game-props.ts` | 把对局状态转成视图 props：揭晓前不带名称、日期和答案 |
| `hooks/kline-chart.ts` | K 线字符图布局 |
| `hooks/game-view.tsx` | 游戏视图绘制 |
| `hooks/game-surface.tsx` | 游戏的 Client 模块：按键、按钮、逐根揭晓 |
