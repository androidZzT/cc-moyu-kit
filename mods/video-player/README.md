# video-player

在 Claude Code 侧边面板里播放本地视频或网络视频，agent 跑长任务的时候看点东西，不用切出终端。

- **画面**：本机 ffmpeg 把视频解成 640 宽的原始 RGB 帧，终端直接读帧文件显示、不用解码，面板其余部分不重绘
- **声音**：本机 ffplay 无窗口播放音轨，和第一帧同时开始
- **按时间推进**：画面按真实时间走，解码跟不上时停在最后一帧等待，不会加速或跳回
- **播放控制**：暂停/继续、前后跳 10 秒、可点击的进度条
- **网络视频**：直链直接读；B 站、YouTube 等网页链接用本机 yt-dlp 解析出画面和声音地址
- **音画对齐**：声音真正出声后，画面时钟对齐到声音的位置，网络起播慢也不会音画错开
- **单独的音量**：不动系统音量，0–100% 和静音，跨会话记住
- **占用可控**：解码只领先播放约 2 秒，播过的帧每秒删除一次，15 fps 下临时目录常驻约 30 MB，和片长无关
- **低打扰**：不抢输入焦点，不弹窗；出错时面板或命令回复里给一行提示

## 要求

| 要求 | 说明 |
| --- | --- |
| ffmpeg、ffprobe | 必需。macOS 上 `brew install ffmpeg`，会一起装上 ffplay |
| ffplay | 可选。没有时只放画面，状态行注明「无声音」 |
| yt-dlp | 可选，只有网页链接需要：`brew install yt-dlp`。直链不需要 |
| 能显示图片的终端 | kitty、Ghostty 等支持图形协议的终端。其他终端看不到画面，播放会停下并提示换终端 |
| 终端界面 | desktop、vscode 等界面打开面板只显示一行提示 |

目前只在 macOS + Ghostty 上验证过。

## 加载

在 Claude Code 终端会话里安装（默认装在用户范围，所有项目都可用）：

```
/plugin install video-player --marketplace androidZzT/cc-moyu-kit
```

或者从源码加载：

```bash
claude --plugin-dir /path/to/cc-moyu-kit/mods/video-player
```

## 命令

| 命令 | 作用 |
| --- | --- |
| `/video <绝对路径> [fps]` | 打开面板播放这个文件；fps 1–60，默认 15。正在播放时会先停掉旧的 |
| `/video <http(s) 链接> [fps]` | 播放网络视频：ffprobe 能直接读的直链照原样播放，读不了的交给 yt-dlp 解析（单个视频，短边不超过 480，优先 H.264） |
| `/video pause` | 暂停：画面停在当前帧，声音停止 |
| `/video resume` | 从暂停的位置继续 |
| `/video seek <位置>` | 跳转：`05:30`、`330`（秒）跳到绝对位置，`+10`、`-10` 相对跳；暂停中跳转会直接开始播放 |
| `/video volume <0–100>` | 设视频音量，取消静音 |
| `/video mute` | 切换静音 |
| `/video stop` | 停止画面和声音，删除临时帧，关闭面板 |

路径里可以有空格，也可以用引号括起来：`/video "/Users/me/My Movie.mkv" 24`。

画面下方两行：

```
━━━━━━━━━━━━━━━━━━━━──────────────────────────────────────────
[⏸ 暂停] [« 10s] [10s »] [🔉] [🔊] [🔇] 01:05 / 14:48 · 15 fps · 音量 100%
```

- 进度条和面板一样宽，点击任意一格跳到对应位置
- 按钮可以用鼠标点；先点一下面板让它拿到焦点，就可以用快捷键：`p` 暂停/继续，`h` 后退 10 秒，`l` 前进 10 秒，`j`/`k` 音量减/加 10%，`m` 静音。快捷键只在面板有焦点时生效，不影响输入框
- 状态行依次是当前位置、总时长、最近一秒实际显示的帧数、音量（或「静音」）；暂停时以「⏸」开头。实际帧数明显低于设定值，说明终端绘制跟不上，可以把 fps 调低

- 调音量只重启声音、画面不动：ffplay 运行中改不了音量，所以从当前位置以新音量重新起播，每次调整声音会断约 0.1–0.3 秒；最高 100%，不能放大。视频没有声音时不显示音量按钮

## 网络视频

- 先用 ffprobe 直接读链接；读不出视频（网页）再调用 yt-dlp，命令回复会等解析完成，通常几秒
- yt-dlp 给出的画面地址、声音地址分别交给 ffmpeg 和 ffplay，请求头（Referer、User-Agent）一起带上；B 站不带会 403
- 画面和声音各一条连接，480p 下合计约 1 Mbps
- 解析出的地址几小时后过期，过期后跳转会失败，重新 `/video` 一次即可
- 网速跟不上时画面停在最后一帧等，声音有自己的缓冲会继续；下次继续或跳转时重新对齐

不支持：直播、需要登录或 cookie 的内容、播放列表、字幕、倍速。

## 临时文件

- 帧写在 `$TMPDIR/cc-moyu-video/play.XXXXXX/s<段号>/` 下：每次播放一个目录，每次继续或跳转开一个新段，新段出画面后删除旧段
- 原始 RGB 帧每帧约 520 KB（640×272），比 PNG 大，但终端不用解码
- 播完、`/video stop`、换片时删除本次目录
- 会话启动时删除 10 分钟内没动过的目录：那是之前的会话被重载或退出打断后留下的。正在播放的目录每秒都有变化，暂停中的目录每分钟 touch 一次，都不会被误删

## 开发

```bash
claude plugin validate .
claude plugin test .
npx -p typescript tsc -p .   # 先用 --plugin-dir 加载一次，生成 .claude-plugin/types
```

| 文件 | 内容 |
| --- | --- |
| `hooks/register.tsx` | 所有用到 `$` 的逻辑：命令、分段与进程、计时、换帧、暂停与跳转、音量、渲染、state 与 store |
| `hooks/plan.ts` | 参数解析，ffmpeg/ffprobe/ffplay 命令行（含 `-ss`、请求头），解析它们的输出（含 ffplay 的声音时钟），帧尺寸 |
| `hooks/timeline.ts` | 帧号、是否播完、状态行、该删哪些帧、画面行数、跳转目标、进度条格子 |
| `hooks/cleanup.ts` | 临时目录位置，遗留目录的查找与过滤 |
| `hooks/source.ts` | 链接判断、yt-dlp 命令行与输出解析、请求头参数 |
| `hooks/volume.ts` | 音量设定的校验、加减、静音、状态行标签 |

测试里的 `tests/harness.ts` 在 mod 下面模拟时钟、终端、`which`/`ffprobe`/`rm` 等命令，以及可由测试喂进度、结束或被 mod 结束的 ffmpeg/ffplay 子进程。
